# Bing Clean

A uBlock Origin filter list for Bing. It hides the Copilot answer, the AI mode tab, the MSN feed and ads, and it blocks Bing's telemetry, location reporting and tracking parameters. Microsoft Rewards keeps working: searches, the Daily Set and quizzes still earn points.

[Click to add to uBlock Origin](https://subscribe.adblockplus.org/?location=https%3A%2F%2Fraw.githubusercontent.com%2Fzoltrons%2Fbing-clean%2Fmain%2Fbing-clean.txt&title=Bing%20Clean)

uBlock Origin opens a confirmation page when you click the link. If it doesn't, add the list by hand: open the uBO dashboard, go to Filter lists, open Import at the bottom, paste the URL below and click Apply changes.

```
https://raw.githubusercontent.com/zoltrons/bing-clean/main/bing-clean.txt
```

## What it removes

On search results:

- the "This summary was generated by AI" Copilot answer at the top
- the AI MODE tab and other Copilot links
- "People also ask" and search ads
- the floating Feedback button, "Advertise" in the menu and the visual search data pop-up

On the homepage, the MSN news and ad feed is hidden. So are the MSN, Online Games, Microsoft 365 and "Get to Know Bing" entries in the overflow menu.

In Rewards, the list hides the Bing Wallpaper, "Redeem now" game promo and refer-a-friend cards in the header panel. On rewards.bing.com it hides the Wallpaper ad under "Your perks" and the Refer and Earn link. These rules were checked against a signed-in account, and they only match cards that award no points.

## What it blocks

- Bing's event and click logging (`/fd/ls/`, `xlsc.aspx`), plus feedback and notification requests
- `/geolocation/write`, which sends your exact latitude and longitude with every search
- Microsoft ad and analytics domains: `bat.bing.com`, `c.bing.com`, `c.msn.com`, `browser.events.data.msn.com`, `clarity.ms`, `ads.msn.com`
- autosuggest, which sends each keystroke to Bing as you type. Search suggestions go away with it.

It also strips tracking parameters. On Bing it removes `cvid`, `qs`, `sp`, `lq`, `pq`, `sc`, `sk`, `gh*`, `ajf` and `qpvt`. On every site it removes `msclkid`, `WT.mc_id`, `utm_*` and `mkt_tok`.

## What it leaves alone for Rewards

Rewards counts points through `/rewardsapp/`, so the list doesn't touch it, the Rewards panel or rewards.bing.com. It also keeps the `FORM`, `form`, `OCID`, `PUBL` and `CREA` parameters, which Daily Set links use to credit an activity.

The Copilot chat container stays visible, and the `/turing/` and `/sydney/` backends stay unblocked. Some Daily Set quizzes open as a Copilot conversation (`filters=IsConversation`), and blocking either would break them. The AI answer on ordinary searches is still hidden.

## Skipping the click-tracking redirect

Result links on Bing go through `bing.com/ck/a?...&u=a1<base64>` before they reach the site. The last rule in the list decodes the target and goes straight there. It uses `urlskip`, which uBlock Origin only runs from a trusted source, so it is ignored when you subscribe to the list. To use it:

1. In uBO settings, enable "Allow custom filters requiring trust".
2. Paste this line into My filters:

```
||bing.com/ck/a?$urlskip=/[?&]u=a1([^&]+)/ -safebase64
```

Bing's own internal links (Images, Videos and so on) decode to a relative path, which isn't a valid URL, so the rule skips them and they work as before.

## Optional

To hide the video carousel too, add this line to My filters:

```
bing.com###b_topw > li.b_vidAns
```

## Known limits

Bing renames its classes often, so a hiding rule can stop matching after an update. If something comes back, pick it with uBO's element picker and open an issue with the selector.

Rewards doesn't appear to rely on `/fd/ls/`, but that hasn't been tested through a full Daily Set. If your points stop adding up, disable that line first.
